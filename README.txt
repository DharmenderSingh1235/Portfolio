# Dharmender Singh — Animated Portfolio

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` directly in a browser, or use the **Live Server** extension.
4. Your profile image is already included at `assets/profile.jpg`.

## Before publishing
- Replace `your-email@example.com` in `index.html` with your real email.
- Replace/add your Live Demo URLs as your projects are deployed.
- Add your final resume PDF if you want a Resume button.

## Included
- Responsive design
- Scroll reveal animations
- Animated particles
- Cursor glow
- Animated progress bar
- Mobile navigation
- Project cards
- Skills, certificates and contact sections
- Reduced-motion accessibility support


## Add your CV / Resume
Copy your CV PDF into the `assets` folder and name it exactly `Dharmender_Singh_CV.pdf`. The View CV and Download CV buttons will then work. Replace the email and LinkedIn placeholders in `index.html` before publishing.
